# Runs of the acceptance scenarios

Each row is one run of the [acceptance scenarios](panel.md#regression-scenarios) (`PR-n`, in the `.feature` files of this folder) on one build. Add a row for every run: the commit or the version of the build, who ran it (the owner by hand, or an agent and the tool it used), the scenarios that passed, and what failed or was not run, with the reason. A scenario that failed and was fixed stays in its row; the run after the fix gets a row of its own.

`make checklist` renders what to run ([how to select](panel.md#regression-scenarios)); the filled-in checklist is the source of a row.
