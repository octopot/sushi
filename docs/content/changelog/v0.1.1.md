# v0.1.1 — Every missing piece, one click away.

A Mac without Ollama or its model no longer leaves the first edit guessing. Press **⌘K**, and Susi says what is missing before you pick an action; run an edit anyway, and the line above the bottom bar says it at once, with a link to the download or the command to copy. Typing, versions, the library, **⌘↵** and **Turn into goal** work without Ollama, as before.

## Without Ollama

- An edit stops at once with *Ollama is not installed on this Mac*, instead of waiting about twelve seconds and asking you to start it. **Download Ollama** on the same line opens the download page in your browser.
- **⌘K** shows the same note above its field. Actions that need no model, such as **Turn into goal**, still run.

## Without the model

- The line reads *Install the local model with* `ollama pull qwen3.5:4b-mlx`. Click the command to copy it, run it in Terminal, and edit again once it finishes. Susi never downloads the model by itself.
- **⌘K** notes a missing model too, before you choose an action.

## With the Ollama command-line tool

- With only the `ollama` command installed, for example through `brew install ollama`, the first edit starts `ollama serve` in the background, as it starts the Ollama app. The server keeps running after you quit Susi.
- If the server does not answer in time, the line says *Ollama did not start* and offers `ollama serve` to copy.

## Installation

- Installing or upgrading Susi with Homebrew no longer prints a deprecation warning about the cask.

**Upgrade:** run `brew upgrade --cask octolab/tap/susi`. Homebrew quits Susi, replaces it and opens it again.
