# v0.1.0 — One keystroke from a better prompt.

**First release**

The prompt you give a coding agent decides what you get back, and it deserves an editor. Susi’s first release puts one on **⌘⇧Space**: write or dictate the task, select what needs work and press **⌘K**, and a model on your Mac rewrites it as a diff right in your text. **⌘←** and **⌘→** walk every version, and **⌘↵** copies the prompt and takes you back to the app you came from.

## A panel over any app

- **⌘⇧Space** shows a Liquid Glass panel with one text field over the app you are in, and hides it again.
- Susi lives in the menu bar, with **Show Susi**, **Open Settings Folder** and **Quit**, and has no Dock icon.
- Your draft and its versions are kept when you hide the panel or quit Susi. Should a long history ever outgrow the storage, Susi keeps your first text and the latest steps, and merges the edits in between into one.

## Rewrite what you select

- Select a phrase, a sentence or a paragraph and press **⌘K**, or right-click it. With nothing selected, the action takes the whole prompt.
- Six actions come ready: **Shorten**, **Fix grammar**, **Clarify**, **Make specific**, **Structure** and **Turn into goal**. Type any part of a name to find one; `shrtn` finds **Shorten**.
- The answer replaces the selection as an inline diff: new words on green, old ones struck through. The text is locked while the model works, and **Esc** cancels.

[Edit and compare versions →](/guide/editing/)

## Every version, one keystroke apart

- Each edit adds a version to one chain: your text, the diff, the result. Right after an edit or a step, **⌘←** or **⌘Z** steps back to the first words you wrote, and **⌘→** or **⇧⌘Z** accepts the diff or steps forward. Once you type or open a library entry, these keys edit text again; the arrows at the sides of the panel step at any time.
- **⌘↵** always copies the whole prompt; on a diff, it copies the new version and accepts it.
- **⇧⌘↵** copies the same and starts an empty prompt. After **⌘↵**, the next time you open Susi the prompt you sent is selected: type to start a new one, or press **→** to keep editing.

## Your own words, typed or spoken

- Write what you want done after **⌘K**, and **Enter** sends it to the model as the instruction. A sentence that matches no action comes first in the list.
- Dictate with MacWhisper or a similar tool. A pasted phrase that names an action, such as *“make shorter”* or *«сделай короче»*, runs it at once.

[Dictate with MacWhisper →](/guide/voice/)

## Long prompts as goals

- **Turn into goal** puts `/goal ` in front of the prompt for Claude Code and Codex, on the spot and without the model.

[Long prompts with /goal →](/guide/goal/)

## Templates and prompts on ⌘L

- **⌘L** opens one searchable list of templates, saved prompts and your dictation dictionary. **Tab** or **T**, **P**, **D** switch sections, and **1**–**9** open an entry: **⌘L T 1** opens the first template.
- Everything is a file you own: actions in `rules.json`, prompts and templates as Markdown. Three templates come ready: *Task brief*, *Bug report* and *Release review*. Point `library-path.txt` at a folder you already keep, such as a Tuna assistant’s `Input`.

[Library and files →](/guide/library/)

## Local by design

- Edits run on Ollama with `qwen3.5:4b-mlx` at `127.0.0.1`. Susi checks that the model is local before it sends any text, and refuses one that Ollama would forward to a cloud service.
- The first edit starts Ollama if it is not running, and **⌘K** asks a running Ollama to load the model ahead of time.
- One edit takes up to 12 KB of text and instruction: for a long prompt, select the passage to change.

[Local model →](/guide/model/)

This release edits with one local model through Ollama. Another model or a cloud provider, built-in dictation, editing actions and templates inside the panel, dictionary replacement and a different shortcut are not included. Susi needs a Mac with Apple Silicon and macOS 26 or later.

**Install:** run `brew install --cask octolab/tap/susi`, then download the model with `ollama pull qwen3.5:4b-mlx`. For a manual installation, download `susi_0.1.0_darwin-arm64.zip` from the [v0.1.0 release](https://github.com/octopot/susi/releases/tag/v0.1.0); this build is not notarized yet, so macOS asks you to confirm opening it the first time, as the [quick start](/quick-start/#download-instead) shows. Then press **⌘⇧Space**.
