# Quick start

Install Sushi and the model, then write, edit and send your first prompt. Most of the time goes to the model download.

**Still have Susi, Sushi's name before v0.2.0?** Since v0.3.0 Sushi no longer brings Susi's files over by itself. Upgrade with `brew upgrade --cask octolab/tap/sushi`, then, before you open Sushi for the first time, copy the folder: `cp -R ~/Library/Application\ Support/me.octopot.susi ~/Library/Application\ Support/me.octopot.sushi`. Your actions, dictionary and library come along; the prompt left open in Susi does not.

## What you need

- A Mac with {release.chip}, running macOS {release.macos} or later.
- [Ollama](https://ollama.com/download), the Mac app or the `ollama` command. Sushi starts it when an edit needs it, and links to the download if it is missing.
- [Homebrew](https://brew.sh), for the recommended install.

## 1. Install Sushi

```sh
brew install --cask octolab/tap/sushi
```

### Download instead

Download <code>{release.archive}</code> from the <a href={release.download}>v{release.version} release</a>, unzip it and move **Sushi** to Applications.

This build is not notarized yet, so macOS stops the first launch and says it cannot verify Sushi. Open **System Settings → Privacy & Security**, find the message about Sushi near the bottom and click **Open Anyway**. macOS asks once; later launches open normally.

## 2. Download the model

```sh
ollama pull qwen3.5:4b-mlx
```

Sushi edits with this model only. It runs inside Ollama on your Mac, and Sushi checks that it is local before it sends any text. [More about the model →](/guide/model/)

## 3. Open the panel

Launch Sushi from Applications, or run `open -a Sushi`. The panel appears, and the Sushi icon appears in the menu bar. Sushi has no Dock icon.

From now on, **Caps Lock** shows the panel over any app and hides it again. While Sushi runs, Caps Lock no longer switches case; quitting Sushi gives it back. The menu bar icon has **Show Sushi**, the key in use, **Use Caps Lock**, **Open Settings Folder** and **Quit**. With **Use Caps Lock** off, **⌃⇧Space** shows the panel.

If the line above the bottom bar says that Caps Lock is taken or a key could not be registered, see [Troubleshooting](/guide/troubleshooting/#the-shortcut-does-not-work).

## 4. Write a prompt

Type the task, or dictate it with a tool such as MacWhisper. For a first try:

```text
Add a dark mode toggle to the settings screen.
Please make sure that it basically follows the system appearance by default and also remembers whatever the user picked last time.
```

Sushi keeps the draft as you type: hide the panel, quit, come back later, and the text is still there.

## 5. Rewrite part of it

1. Select the second sentence with the mouse or with **⇧** and the arrow keys.
2. Press **⌘K**. The actions list opens above the bottom bar, with the field *What to do with the selection?*
3. Type `short`. **Shorten** is at the top; press **Enter**.

The selection dims while the model works, and **Rewriting…** replaces **Action** in the bottom bar; **Esc** cancels. The first edit can take longer while Ollama loads the model into memory.

The answer replaces the sentence as a diff: new words on green, removed words struck through. The line above the bar reads **Shorten · ⌘← Back · ⌘→ Accept**. Press **⌘←** to see your original text, **⌘→** to come back to the diff, and **⌘→** again to accept it.

With nothing selected, an action takes the whole prompt. [Editing and versions →](/guide/editing/)

## 6. Send it

Press **⌘↵**. Sushi copies the whole prompt, hides, and returns you to the app you came from. Paste it into your coding agent with **⌘V**.

The next time you open Sushi, the prompt you sent is selected. Start typing or dictating for a new prompt, or press **→** or click in the text to keep working on it. **⇧⌘↵** copies the same way and leaves an empty prompt instead.
