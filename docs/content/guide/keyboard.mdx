# Keyboard reference

## Anywhere on your Mac

| Keys | Action |
| --- | --- |
| **Caps Lock** | Show Sushi; press again to hide it. While Sushi runs, Caps Lock does not switch case. |
| **⌃⇧Space** | The same, when **Use Caps Lock** is off in the menu bar menu or Caps Lock is taken. Change it in `hotkey.json`. |

## Change the key

Caps Lock shows Sushi while **Use Caps Lock** is on in the menu bar menu. Sushi maps Caps Lock to a key no keyboard has, on every keyboard, including one you connect later; other key mappings stay as they are, and quitting Sushi gives Caps Lock back. No permission is needed.

Turn **Use Caps Lock** off to keep Caps Lock for capitals: then **⌃⇧Space** shows Sushi. Sushi also falls back to it when macOS switches input sources with Caps Lock or another app already remaps it, and says so in the panel.

Both choices live in `hotkey.json` in the settings folder (**Open Settings Folder** in the menu bar menu):

```json
{
  "capsLock": true,
  "shortcut": "Control+Shift+Space"
}
```

`shortcut` takes modifiers (`Control`, `Option`, `Shift`, `Command`) and one key, joined with `+`: `Option+Command+KeyP`, `Control+Shift+Space`, `Shift+F13`. Sushi reads the file at launch and when you switch **Use Caps Lock**; the switch writes `capsLock` back. To return to ⌘⇧Space, the key of Susi, set `"capsLock": false` and `"shortcut": "Command+Shift+Space"`; on macOS 27 that combination opens Visual Intelligence instead.

## In the panel

| Keys | Action |
| --- | --- |
| **⌘K**, or right-click a selection | Actions on the selection, or on the whole prompt. |
| **⌘L** | The library: templates, prompts and dictionary. |
| **⌘↵** | Copy the prompt, hide Sushi, return to the previous app. On a diff, the copy accepts the edit. |
| **⇧⌘↵** | Copy the same, then start an empty prompt. |
| **Esc** | Close the open list; otherwise cancel a running edit; otherwise hide Sushi without copying. |

## Versions

Right after an edit or a step, until you type:

| Keys | Action |
| --- | --- |
| **⌘←** or **⌘Z** | One step back: from a diff to the text before it. |
| **⌘→** or **⇧⌘Z** | One step forward; on a diff, accept the edit. |

The arrows at the edges of the panel step back and forward at any time. Once you type or open a library entry, **⌘←**, **⌘→**, **⌘Z** and **⇧⌘Z** do their usual editing jobs again. [The version chain →](/guide/editing/#the-version-chain)

## Actions list (⌘K)

| Keys | Action |
| --- | --- |
| Type or dictate | Filter the actions; anything you write is also offered as an instruction. |
| **↑** **↓** | Move through the list. |
| **Enter** | Run the selected action or send your instruction. |
| **⌘K** or **Esc** | Close the list. |

A pasted phrase that names an action runs it without **Enter**. [Dictate with MacWhisper →](/guide/voice/)

## Library (⌘L)

| Keys | Action |
| --- | --- |
| Type | Search templates, prompts and the dictionary. |
| **Tab**, **⇧Tab** | Next or previous section: All, Templates, Prompts, Dictionary. |
| **T**, **P**, **D** on an empty field | Jump to Templates, Prompts or Dictionary. |
| **1**–**9** on an empty field | Open the numbered entry. |
| **↑** **↓**, **Enter** | Choose and open an entry. |
| **⌘L** or **Esc** | Close the library. |

Section letters and numbers follow the key's position, so they work with any keyboard layout. **⌘L T 1** opens the first template.

## The bottom bar

The bar shows each key as a button: **Action ⌘K**, **Library ⌘L** and **Copy ⌘↵**. While an edit runs, **Action** reads **Rewriting… esc**, and a click cancels.
