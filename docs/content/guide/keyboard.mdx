# Keyboard reference

## Anywhere on your Mac

| Keys | Action |
| --- | --- |
| **Caps Lock** | Show Sushi; press again to hide it. While Sushi runs, Caps Lock does not switch case. |
| **⌃⇧Space** | The same, when you choose a keyboard shortcut instead of Caps Lock, or Caps Lock is taken. Change it in [Settings ▸ Keyboard](/guide/settings/#keyboard). |

## Change the key

Open **Settings…** in the menu bar menu, or press **⌘,** in the panel, and choose **Keyboard**.

- **Caps Lock** shows Sushi. Sushi maps Caps Lock to a key no keyboard has, on every keyboard, including one you connect later; other key mappings stay as they are, and quitting Sushi gives Caps Lock back. No permission is needed.
- **Keyboard shortcut** keeps Caps Lock for capitals. Click **Change…** and press the combination you want, with at least one of ⌃, ⌥, ⇧ or ⌘; it is taken when you let go, and **Esc** cancels. **Restore ⌃⇧Space** next to it brings back the default.

With Caps Lock chosen, the combination is the backup: Sushi uses it when macOS switches input sources with Caps Lock or another app already remaps it, and says so in the panel, in the menu bar menu and in Settings. **Show Sushi** in the menu bar menu always shows the key in effect.

### In the file

The choice lives in `hotkey.json` in the settings folder, and you can still edit it by hand:

```json
{
  "capsLock": true,
  "shortcut": "Control+Shift+Space"
}
```

`shortcut` takes modifiers (`Control`, `Option`, `Shift`, `Command`) and one key, joined with `+`: `Option+Command+KeyP`, `Control+Shift+Space`, `Shift+F13`. Sushi reads the file at launch and when you come back to the Settings window, which applies a hand edit at once. To return to ⌘⇧Space, the key of Susi, set `"capsLock": false` and `"shortcut": "Command+Shift+Space"`; on macOS 27 that combination opens Visual Intelligence instead.

## In the panel

| Keys | Action |
| --- | --- |
| **⌘K** | Actions on the selection, or on the whole prompt. A right click opens the usual macOS menu. |
| **⌘,** | Open Settings. |
| **⌘L** | The library: templates, prompts and dictionary. |
| **⌘↵** | Copy the prompt, hide Sushi, return to the previous app. On a diff, the copy accepts the edit. |
| **⇧⌘↵** | Copy the same, then start an empty prompt. |
| **Esc** | Close the open list; otherwise cancel a running edit; otherwise hide Sushi without copying. |

## Versions

Right after an edit or a step, until you type:

| Keys | Action |
| --- | --- |
| **⌘←** or **⌘Z** | One step back: from a diff to the text before it. |
| **⌘→** or **⇧⌘Z** | One step forward; on a diff, accept the edit. |

The arrows at the edges of the panel step back and forward at any time. Once you type or open a library entry, **⌘←**, **⌘→**, **⌘Z** and **⇧⌘Z** do their usual editing jobs again. [The version chain →](/guide/editing/#the-version-chain)

## Actions list (⌘K)

| Keys | Action |
| --- | --- |
| Type or dictate | Filter the actions; anything you write is also offered as an instruction. |
| **↑** **↓** | Move through the list. |
| **Enter** | Run the selected action or send your instruction. |
| **⌘K** or **Esc** | Close the list. |

A pasted phrase that names an action runs it without **Enter**. [Dictate with MacWhisper →](/guide/voice/)

## Library (⌘L)

| Keys | Action |
| --- | --- |
| Type | Search templates, prompts and the dictionary. |
| **Tab**, **⇧Tab** | Next or previous section: All, Templates, Prompts, Dictionary. |
| **T**, **P**, **D** on an empty field | Jump to Templates, Prompts or Dictionary. |
| **1**–**9** on an empty field | Open the numbered entry. |
| **↑** **↓**, **Enter** | Choose and open an entry. |
| **⌘L** or **Esc** | Close the library. |

Section letters and numbers follow the key's position, so they work with any keyboard layout. **⌘L T 1** opens the first template.

## Settings (⌘,)

| Keys | Action |
| --- | --- |
| **⌘1**–**⌘5** | Keyboard, Model, Actions, Library, About. |
| **⌥↑** **⌥↓** | Move the selected action up or down. |
| **⌘Z** | Outside a text field: undo the latest deletion of an action or a term. |
| **⌘W** | Close Settings and return to the app you came from. |

[Settings →](/guide/settings/)

## The bottom bar

The bar shows each key as a button: **Action ⌘K**, **Library ⌘L** and **Copy ⌘↵**. While an edit runs, **Action** reads **Rewriting… esc**, and a click cancels.
